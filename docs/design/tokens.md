CSS では `src/styles/global.css` の `@theme` に入れる。変数名は下の「名前」列のとおり。

## 書体

すべて Google Fonts。

| 役割 | 書体 | 太さ |
| --- | --- | --- |
| 見出し・タイトルの文字 | Murecho | 900（Black）、700（Bold） |
| 本文 | IBM Plex Sans JP | 400、500 |
| ラベル・数字・等幅 | M PLUS 1 Code | 400、500、700 |
| ステートメント（散文） | Shippori Mincho | 400 |

注意：Murecho には「筐」など一部の字がない。足りない字が出たら IBM Plex Sans JP を代わりの書体に指定する（`font-family: "Murecho", "IBM Plex Sans JP", sans-serif`）。

## 有孔ボードの格子

| 項目 | PC | スマホ |
| --- | --- | --- |
| 孔の間隔 | 34px | 22px |
| 最初の孔の位置（x, y） | (33, 16) | (9, 16) |
| 孔の直径 | 5px | 4px |
| ペグの頭の直径 | 9px（縁 1.5px） | 7px（縁 1.2px） |
| タイトルを吊るペグの段 | 文字の段ごとに、その段のすぐ上の孔の列（y = 50 / 186 / 322） | 同じく（y = 82 / 170 / 258） |

ワイヤーの上端は必ず孔の中心に合わせる（格子に吸着させる）。

## タイトルの配置

| 項目 | PC | スマホ |
| --- | --- | --- |
| 1文字の送り | 102px（文字 96 + 6） | 66px |
| 左端（1段目の左端） | 84px | 20px |
| 段ごとの右へのずらし | 0 / 34 / 68px | 0 / 22 / 44px |
| 段の間隔（文字の箱の上端どうし） | 136px（孔 4 つ分） | 88px（孔 4 つ分） |
| 各段の文字の箱の上端 | 82 / 218 / 354px | 92 / 180 / 268px |

段のずらしを孔の間隔の倍数にしているのは、文字の中心の真上に孔が来るようにするため。段の間隔も孔の間隔の倍数にしてあり、どの段もペグから文字までのワイヤーの長さがそろう（以前は全段を同じ高さのペグから吊っていて、下の段ほどワイヤーが長く、上の段の文字を横切っていた）。
