## 経緯（短く）

1. 引継ぎ資料（Claude Docs「制作展サイト 引継ぎ資料」）のデモ集を出発点にした
2. スタイルは「配線とパッチ」の方向に決め、リファレンスを集めて方針を6つに絞った（Figma の References ページ）
3. ポスターのラフに合わせ、最初の画面の構成を決めた
4. 外枠に孔を空ける案（v4）を経て、外枠をやめ、すべてを有孔ボードから吊る案（v5）に決めた
