# 決まりごとと動きの仕様（v5）

展示タイトル「つなぐ、かわる、うまれる、」をそのまま仕組みにしたサイト。ページ全体が1枚の有孔ボードで、載っているものはすべてボードの孔から吊り下がっている。

## 1. 全体の決まりごと

1. **すべて有孔ボードから吊る。** 地は有孔ボード（規則正しく並んだ小さな孔）。札、作品カード、カテゴリーの面、ナビ、タイトルの文字は、どれも板の孔に挿したペグからワイヤーで吊る。
2. **吊られる側にも孔がある。** 札やカードの上端近くにハトメの孔があり、ワイヤーはペグからその孔に通る。つなぎ直しは「孔から孔へ」。
3. **節の範囲の線は引かない。** 各節の下端には、横長の棚（札）を吊って置く。棚もほかの札と同じく、ペグから吊られた物体。
4. **落ちたものは、下にある棚や札の上で止まる。** 棚からこぼれたものも、ページの下端と左右の端の見えない壁で止まり、どこまでも落ちてはいかない。
5. **画面に固定されるのは右上の「ステートメント」ボタンだけ。** ほかはすべてページと一緒にスクロールする。
6. **色は符号。** 段階色（黄・青・赤・緑）は「つながっている」ことを示すもの（点いたペグ、結んだケーブル）だけに使う。面や文字は無彩色。
7. **光らせない。** ネオン、グロウ、グラデーションは使わない。
8. **遊びは脇役。** 会期・会場・作品一覧・リンクは、何も触らなくても読めて使える。
9. **吊られたものはすべて触れる。** 文字だけでなく、札・カード・カテゴリーの面もつかんで動かせ、離すと揺れて戻る（手本はデモ集の M2「WIRED DOM」と A4「降りてくる部品」、`ib/mobile.js`）。
10. **札どうしはぶつかる。** つかんだ札で押すと、押された札はワイヤーが伸びて押しのけられ、離すと揺れながら元に戻る。重ねて通り抜けることはない（モックにはなかったので、実装で足した）。
11. **スクロールの揺れはごくわずか。** スクロールに合わせて、気づくか気づかないか程度に左右へ振れるだけ。

## 2. 節の構成（上から）

| 節 | 中身 |
| --- | --- |
| 最初の画面 | 吊られたタイトル、展示名と副題の札、開催情報の札（右下・大きく）。ナビは節の上のヘッダーに置く |
| 作品 | 見出しの札、カテゴリーの面、作品カード（各カードを2本のワイヤーで吊る） |
| テーマ | ステートメントの第1連の札、「ステートメントを読む」 |
| 開催情報 | 大きな値（会期・教室・時間）の札、詳細の札、地図の札 |
| フッター（ボードの外） | 過去の制作展（アーカイブ）、クレジット、授業名など |

## 3. 画面の流れ

### ① 開いた直後

- タイトル「つなぐ、／かわる、／うまれる」が3段で左上に吊られている。文字1つにつき1本のワイヤー。ワイヤーは、段ごとにその段のすぐ上の孔の列のペグから下りる。
- 吊っているペグの頭が段階色で点く（1段目＝黄、2段目＝青、3段目＝赤）。
- 読点（、）2つはワイヤーなしで、その位置に固定されている（落ちない）。
- ステートメントのモーダルが開いている。ページの上に暗い幕（不透明度 0.35）。
- **ポップアップ（ステートメントのモーダル、作品概要のパネル）は、有孔ボードの孔にワイヤーで留めたカード。**「吊られたまま上から下ろされる」のではなく、画面の上の外から斜めに傾いて回りながら物理で落ちてきて、ペグからのワイヤーに受け止められ、大きく振れてから水平に戻って止まる（ペグより上ではワイヤーはたるんでいる）。揺れは数秒で収める。マウスでつかんで揺らせる（`src/lib/physics/pinned.ts`）。
- 右上の「ステートメント」ボタンは押された状態。

### ② ステートメントを閉じる

- **閉じ方**：モーダルの外を押す。右上の「閉じる ×」と Esc キーでも閉じる。
- モーダルはワイヤーを巻き取って上へ引き上げられて消える。
- **同時に**、タイトルのワイヤーが一斉に切れて先が上へ跳ね、ペグが消灯する。文字は投げたり回したりせず、その場から素直に落ちる（どこにどう積もるかは物理まかせ）。
- 最初に一度だけ起きる演出。2回目以降にステートメントを閉じても、タイトルはもう落ちている。

### ③ 着地（最初の画面）

- 文字は、下にある札や「最初の画面」の下端の棚の上に積もる。文字は軽め（札の 1/3 ほどの密度）で、軽く跳ねて転がる。
- **文字は札にもぶつかる。** 落ちる途中に札（説明の札など）があれば、その上に載る。札が動く（つかまれる・揺れる）と、載っていた文字は起こされて落ち直す。つまんだ文字で札を押すと、札はワイヤーが伸びて押しのけられる。
- 字形の下端が、載った棚や札の上端にちょうど触れる（突き抜けない）。
- タイトル用のペグからは、空のワイヤーの先（小さな環つき）が短く垂れる。
- スマホでは、落ちた直後に一度だけ「文字を押すと、上のフックに順に吊られる」の案内を出す。

### 結び直す

- **文字は特例：押す（クリック・単押し）だけで、まだ文字がつながっていないタイトル用のペグへ、読む順に吊られる。** 床から巻き上げられる（瞬間移動させない）。床の文字にホバーすると、押したときに吊られる先のペグが目立つ。
- **フックに巻き上げられているあいだ、文字は札やほかの文字をすり抜ける**（ページの端の見えない壁にはぶつかる）。上に札があっても引っかからずに吸着する。巻き上げが終わっても何かに重なっていれば、離れるまですり抜けを続ける（急に弾かれないように）。
- 床の文字をつまんで（ドラッグ）、空のワイヤーの先（タイトル用のフックの下）へ持っていくと、そこに吊れる。文字を吊れるのはタイトル用のフックだけで、板のほかの孔には吊らない（どこに戻せばよいかを迷わせないため）。
- **ケーブルの側からも結べる**（引継ぎ資料の B3「ポスター」）。空のワイヤーの先をつまむと、たるんだワイヤーが指まで伸びてうねりながら追う。46px 以内のいちばん近い文字の輪郭が出て、離すとその文字に結ばれ、床から巻き上げられる。何もないところで離すと、垂れ落ちながら短く巻き戻る。空のワイヤーの先を押してから文字を押しても結べる。
- 吊るとペグが点く。

### 札のワイヤーも挿し替えられる

- 札・カード・カテゴリーの面のペグは、つまんで別の孔へ挿し替えられる（ドラッグ。または、ペグを押して選んでから行き先の孔の辺りを押す）。挿さる先の孔は点線の輪で見せる。
- 札は新しいペグの下へ揺れて移り、そこで止まる（元の位置へは戻らない）。画面の大きさが変わって並びが変わったときは、元のペグに戻る。
- **ペグの高さが違えば、札はその差に合わせて傾いて吊られる**（ワイヤーは垂直に垂れ、孔がそれぞれのペグの真下に来る。ワイヤーの長さはそろえ直す）。傾きは 1 ラジアン（約 57°）まで。傾いた札にも、ほかの札や文字は傾いた形のままぶつかる（文字は斜めの上辺に載り、すべり落ちることもある）。

### ホバーの手がかり

- 吊られたものにホバーすると、そのペグと吊られる側の孔が少し跳ねて大きくなり、ワイヤーが濃く太くなる。どこで吊られていて、どこをつまめるかを示す。ペグを選んでいるあいだは、そのペグが脈打つ。
- 動きを減らす設定では、跳ねずに大きくなるだけ。

### ④ 作品概要

- 作品カードを押すと、作品概要のパネルが画面の上の外から落ちてきて、板の孔のペグからの2本のワイヤーに受け止められ、振れてから止まる（①の「作品概要のパネルは…」）。暗い幕つき。
- 閉じ方はステートメントと同じ（外を押す／閉じる ×／Esc）。閉じるとワイヤーを巻き取って上へ引き上げられる。閉じたあとは、元のカードにフォーカスを戻す（Issue #6）。

### 右上の「ステートメント」ボタン

- いつでも押せる。押すと①と同じステートメントのモーダルが落ちてきて、ワイヤーに受け止められる。

## 4. 作品の絞り込み

- カテゴリーの面に、カテゴリーの言葉と端子（ジャック）が並ぶ。
- 端子どうしをケーブルでつなぐと、**両方のカテゴリーをもつ作品だけ**が吊られた状態で残る（AND）。複数の組をつないだら、どれかの組を満たす作品（AND の OR）。
- つないだケーブルは黄色（つなぐ）、端子の横のランプが点く。ケーブルの真ん中に件数のラベル（例：「2作品」）。
- 0件の組は「まだない／新しい関係かもしれない」と出す。
- ケーブルを押すと抜ける。
- **カードの出入りは元気よく。** 絞り込みで新しく出てくるカードは、少し上から斜めに傾いて勢いよく落ちてきて、ワイヤーに受け止められて揺れる。並びが変わって位置が動くカードは、いまの場所から新しいペグに引かれて揺れながら移る（ページを開いたときの最初の配置は落とさない）。
- **操作の手触りは引継ぎ資料の B5「言葉の面」に合わせる**（デモ集の `ib/b5.html`、`ib/tie.js`、`ib/cable.js`）。端子をつかむとたるんだケーブルが出て、指を追ってうねる。46px 以内のいちばん近い端子だけが光り、離すとつながる。動かさずに離すとタップ→タップ。つないだケーブルは垂れて揺れ、マウスでなでると揺れる。ケーブルを直線や固定の曲線で描かない。

## 5. 落ちるものの一般則

- ワイヤーが全部抜けた部品は、下にある棚や札の上まで落ちて止まる。
- 例：作品カードのワイヤーが抜けると、作品の節の下端の棚の上で傾いて止まる（Figma `79:873` は床の線だった頃の絵）。
- 実装の最初の段階では、タイトルの文字だけに適用してよい。

## 6. 動きと読みやすさ

- 吊られたものは、わずかに揺れてよい（振り子）。止まっているときは静か。
- ドラッグ中、つかんだ点は常にカーソルの真下にあること（ずれ 0px）。
- `prefers-reduced-motion` のときは、自動の落下・揺れをやめる。②ではタイトルは落とさずに吊ったままにする。ユーザーの操作への追従はやめない。
- ポップアップはキーボードで開閉できる。開いている間はフォーカスを中に閉じ込め、閉じたら元に戻す。
- 吊られた文字は絵として描くので、展示名は別に `h1` で読めるようにする。
