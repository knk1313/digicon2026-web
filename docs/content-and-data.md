# サイトに載せる情報とデータの形

## 載せる情報とデータの対応

### サイト全体の情報

| 載せる情報 | 項目名 | 型 |
| --- | --- | --- |
| 制作展の名前 | `title` | 文字列 |
| 会期 | `period` | 開始日と終了日 |
| テーマ | `theme` | 文字列 |
| 会場 | `venue` | 名前 |
| 授業の紹介 | `about` | 文章 |

### 作品ごとの情報

| 載せる情報 | 項目名 | 型 |
| --- | --- | --- |
| 作品名 | `title` | 文字列 |
| 制作者 | `authors` | 名前 |
| 説明 | `description` | 文章 |
| サムネイル | `thumbnail` | 画像 |
| 画像 | `images` | 画像の一覧 |

## 置き場所（仮）

- **サイト全体の情報**：`src/data/site.json`
- **作品ごとの情報**：`src/content/works/<学籍番号>.md`
- **画像**：各Markdownと同じフォルダーに置く
