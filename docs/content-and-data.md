# サイトに載せる情報とデータの形

## 載せる情報とデータの対応

### サイト全体の情報

| 載せる情報 | 項目名 | 型 |
| --- | --- | --- |
| 制作展の名前 | `title` | 文字列 |
| 会期 | `period` | 開始日と終了日 |
| テーマ | `theme` | 文字列 |
| 会場 | `venue` | 名前 |
| X アカウント | `x` | URL（`https://x.com/itf_digicon2026`） |
| 授業の紹介 | `about` | 文章 |

### 作品ごとの情報

| 載せる情報 | 項目名 | 型 |
| --- | --- | --- |
| 作品番号 | `id` | 文字列（`"01"` など） |
| 作品名 | `title` | 文字列 |
| 制作者 | `authors` | 名前の一覧 |
| 説明（短文） | `summary` | 文章 |
| 説明（長文） | `description` | 文章 |
| サムネイル | `thumbnail` | 画像 |
| カテゴリー | `categories` | 文字列の一覧（1つ以上）。トップページの絞り込みで、つないだ2つのカテゴリーを両方もつ作品だけを残すために使う |
| 画像 | `images` | 画像の一覧（未使用） |

### デモデータ

実装中は `src/data/demo.json` を使う。サイト全体の情報と作品の一覧が1つのファイルに入っている。ステートメントは `theme.statement` に、連を空行、行を改行、句を全角スペースで区切って入れる。

## 置き場所（仮）

- **サイト全体の情報**：`src/data/site.json`
- **作品ごとの情報**：`src/content/works/<学籍番号>.md`
- **画像**：各Markdownと同じフォルダーに置く
